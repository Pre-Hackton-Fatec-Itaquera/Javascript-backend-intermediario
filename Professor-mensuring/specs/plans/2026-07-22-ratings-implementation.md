# Ratings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add anonymous professor ratings (1-5) per subject, with many-to-many professor-subject relationship.

**Architecture:** Two new tables (`professor_subject` for many-to-many, `ratings` for evaluations) plus removal of `subjectId` and `averageRating` from `professor`. Average computed via query aggregation.

**Tech Stack:** Drizzle ORM + PostgreSQL (via postgres.js), Fastify + Zod

### Task 1: Create `professor_subject` table schema

**Files:**
- Create: `src/db/schemas/professorSubject.ts`

- [ ] **Step 1: Create `src/db/schemas/professorSubject.ts`**

```typescript
import { pgTable, uuid, unique } from "drizzle-orm/pg-core";
import { professor } from "./professor.ts";
import { subjects } from "./subject.ts";

export const professorSubject = pgTable('professor_subject', {
    id: uuid().primaryKey().defaultRandom(),
    professorId: uuid().notNull().references(() => professor.id, { onDelete: "cascade" }),
    subjectId: uuid().notNull().references(() => subjects.id, { onDelete: "cascade" }),
}, (t) => [
    unique().on(t.professorId, t.subjectId),
]);
```

### Task 2: Create `ratings` table schema

**Files:**
- Create: `src/db/schemas/ratings.ts`

- [ ] **Step 1: Create `src/db/schemas/ratings.ts`**

```typescript
import { pgTable, uuid, integer, varchar, timestamp, check } from "drizzle-orm/pg-core";
import { sql } from "drizzle-orm";
import { professorSubject } from "./professorSubject.ts";

export const ratings = pgTable('ratings', {
    id: uuid().primaryKey().defaultRandom(),
    value: integer().notNull(),
    comment: varchar({ length: 255 }),
    createdAt: timestamp().defaultNow().notNull(),
    professorSubjectId: uuid().notNull().references(() => professorSubject.id, { onDelete: "cascade" }),
}, (t) => [
    check("rating_value_check", sql`${t.value} >= 1 AND ${t.value} <= 5`),
]);
```
