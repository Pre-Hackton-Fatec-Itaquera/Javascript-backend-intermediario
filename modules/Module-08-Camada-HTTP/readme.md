# Módulo 08 - Camada HTTP

Neste módulo iremos construir a camada HTTP da aplicação.

Ao final dele você será capaz de:

- Entender como uma API REST funciona.
- Utilizar os principais métodos HTTP.
- Organizar uma feature utilizando a arquitetura do projeto.
- Criar schemas utilizando o Zod.
- Implementar rotas no Fastify.
- Criar Services e Repositories.
- Registrar as rotas no servidor.
- Realizar testes utilizando arquivos `.http`.

Estrutura do módulo:

- arquitetura.md
- rotas.md

Todos os exemplos apresentados neste módulo são retirados do domínio `Professor`, utilizado no projeto principal.
