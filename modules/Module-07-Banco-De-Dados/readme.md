# Módulo 07 - Banco de Dados

Até aqui já possuímos:

- Um projeto Node.js configurado.
- Um servidor Fastify.
- Um container PostgreSQL rodando através do Docker.

Agora chegou a hora de configurar o nosso banco de dados dentro da aplicação.

Neste módulo iremos aprender:

- O que é um ORM.
- Como configurar o Drizzle ORM.
- Como criar a conexão com o PostgreSQL.
- Como definir nossas tabelas utilizando TypeScript.
- Como gerar e executar migrations.
- Como utilizar o Drizzle Studio para visualizar os dados.

Ao final deste módulo, teremos um banco de dados totalmente funcional e pronto para ser utilizado pela nossa API.

Arquivos deste módulo:

- configuracao.md
- conexao.md
- schemas.md
- migrations.md
