Imagine que você acabou de entrar em uma equipe de desenvolvimento.

Um dos desenvolvedores utiliza:

- PostgreSQL 15
- Windows

Outro utiliza:

- PostgreSQL 17
- Ubuntu

Outro utiliza:

- PostgreSQL 16
- MacOS

Agora imagine tentar fazer um projeto funcionar na máquina de todos.

É justamente esse tipo de problema que o Docker resolve.

Ele nos permite executar aplicações isoladas dentro de containers, garantindo que todos estejam utilizando exatamente o mesmo ambiente de desenvolvimento.

Podemos pensar em um container como um pequeno computador isolado executando uma única aplicação.
No nosso caso, esse pequeno computador estará executando apenas o PostgreSQL.

Caso tenha interesse, procure saber mais sobre docker
